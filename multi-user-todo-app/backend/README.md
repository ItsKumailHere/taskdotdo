# Multi-User Todo Backend

Backend API for the Multi-User Todo Application built with FastAPI and SQLModel.

## Features

- RESTful API endpoints
- JWT-based authentication with Better Auth
- User data isolation
- CRUD operations for todos, categories, and tags
- Database integration with Neon Serverless Postgres

## Tech Stack

- **Framework**: FastAPI
- **Database ORM**: SQLModel
- **Database**: Neon Serverless Postgres
- **Authentication**: Better Auth JWT verification
- **Python Version**: 3.12+

## Setup

1. Install dependencies:
   ```bash
   pip install -e .
   ```

2. Configure environment variables in `.env`:
   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/todo_app"
   SECRET_KEY="your-super-secret-key-here"
   ALGORITHM="HS256"
   ACCESS_TOKEN_EXPIRE_MINUTES=129600  # 90 days in minutes
   FRONTEND_URL="http://localhost:3000"
   ```

3. Run the application:
   ```bash
   uvicorn main:app --reload --port 8000
   ```

## API Documentation

API documentation is available at `/docs` when running in development mode.

## Authentication

The backend verifies JWT tokens generated by Better Auth using the shared secret. Better Auth is a frontend authentication library that runs on the client side. All protected endpoints require a valid Better Auth JWT token in the Authorization header.

## Database Models

- User: Stores user information
- Todo: Represents individual tasks
- Category: Organizes todos into groups
- Tag: Adds labels to todos
- Notification: Manages user notifications
