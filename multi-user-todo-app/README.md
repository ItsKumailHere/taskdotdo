# Multi-User Todo Application

A full-stack web application that allows multiple users to manage their personal todo lists with features for organization, categorization, and notifications.

## Features

- **Multi-user support**: Each user has their own isolated data
- **Todo management**: Create, read, update, and delete todos
- **Organization**: Categorize todos and add tags
- **Authentication**: Secure login and registration with Better Auth
- **Responsive UI**: Works on desktop and mobile devices
- **Dark/Light theme**: User preference for color scheme
- **Notifications**: Reminders for upcoming due dates

## Tech Stack

### Backend
- **Framework**: FastAPI
- **Database ORM**: SQLModel
- **Database**: PostgreSQL (with Neon Serverless support)
- **Authentication**: JWT token verification (tokens generated by Better Auth)
- **Python Version**: 3.11+

### Frontend
- **Framework**: Next.js 16 (App Router)
- **Authentication**: Better Auth
- **Styling**: Tailwind CSS
- **Language**: TypeScript

## Environment Variables

### Backend (.env)
- `DATABASE_URL`: PostgreSQL connection string
- `SECRET_KEY`: Secret key for JWT signing
- `ALGORITHM`: JWT algorithm (default: HS256)
- `ACCESS_TOKEN_EXPIRE_MINUTES`: Token expiration time
- `FRONTEND_URL`: URL of the frontend for CORS

### Frontend (.env.local)
- `NEXT_PUBLIC_API_URL`: URL of the backend API

## Authentication

The application uses Better Auth for frontend authentication. The backend verifies JWT tokens generated by Better Auth using the shared secret.

## Database Schema

The application uses the following main models:
- **User**: Stores user information
- **Todo**: Individual tasks with descriptions, due dates, completion status
- **Category**: Organizes todos into groups
- **Tag**: Adds labels to todos
- **Notification**: Manages user notifications
- **Session**: Tracks user sessions
