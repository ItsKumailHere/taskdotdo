# Quickstart Guide: Multi-User Todo Application

This guide provides a quick overview of how to set up and run the multi-user todo application.

## Prerequisites

- Python 3.11+
- Node.js 18+
- PostgreSQL
- Git

## Setup Steps

### 1. Clone and Navigate to Project

```bash
cd multi-user-todo-app
```

### 2. Backend Setup

1. Navigate to backend:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   python3 -m pip install --break-system-packages -e .
   ```

3. Create `.env` file with:
   ```env
   DATABASE_URL=postgresql://username:password@localhost:5432/todo_app
   SECRET_KEY=your-super-secret-key-change-in-production
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=129600  # 90 days in minutes
   DEBUG=True
   FRONTEND_URL=http://localhost:3000
   ```

4. Start backend server:
   ```bash
   python3 -m uvicorn main:app --reload --port 8000
   ```

### 3. Frontend Setup

1. Open a new terminal and navigate to frontend:
   ```bash
   cd frontend  # (from project root)
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create `.env.local` file with:
   ```env
   NEXT_PUBLIC_API_URL=http://localhost:8000
   ```

4. Start frontend server:
   ```bash
   npm run dev
   ```

## Access the Application

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Documentation: http://localhost:8000/docs

## Key Features

- User registration and authentication via Better Auth
- Todo management (create, read, update, delete)
- Category and tag organization
- Dark/light theme toggle
- User data isolation (each user sees only their own data)
- Session management

## Architecture Notes

- **Backend**: FastAPI + SQLModel + PostgreSQL
- **Frontend**: Next.js 16 + Better Auth
- **Authentication**: JWT tokens generated by Better Auth and verified by backend
- **Database**: PostgreSQL with Neon Serverless support
